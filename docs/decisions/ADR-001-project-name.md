# ADR-001: Project Name = Samverk

**Status**: Accepted
**Date**: 2026-02-26

## Context

30+ candidates researched across Norse mythology, Latin/Greek forge concepts, and invented compounds. Nearly all viable options were taken by funded US tech companies.

## Decision

Use the Icelandic word "samverk" (cooperative work).

## Consequences

**Positive:**

- Perfect conceptual fit -- literally means what the framework does
- No US tech/software conflicts found
- Personal connection to Iceland (founder lived there)
- All-standard Latin letters, keyboard-friendly
- Authentic rather than invented

**Negative:**

- .com domain is taken by an unrelated Norwegian hotel co-op
- Will use alternative TLD (.io or .ai)
